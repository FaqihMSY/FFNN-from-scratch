# FFNN-from-scratch
Kelompok 3 - Geprek ML

## Deskripsi Repository
Repository ini merupakan Tugas Besar I pada kuliah IF3270 Pembelajaran Mesin memiliki tujuan agar peserta kuliah mendapatkan wawasan tentang bagaimana cara mengimplementasikan Feedforward Neural Network (FFNN). Pada tugas ini, peserta kuliah akan ditugaskan untuk mengimplementasikan FFNN from scratch. Pada folder src berisi kumpulan kode program sedangkan pada folder doc berisi laporan akhir.

## Cara Setup dan Run
Cukup run file src/main.ipynb saja
